# MEMORIZE EAD

Feito a partir do Projeto de Extensão Fábrica de Software, o MEMORIZE EAD foi idealizado e construído com o intuito de ajudar os estudantes visitantes do UNISAGRADO na Feira de Profissões a escolherem a melhor opção de cursos para si na modalidade EAD, exibindo detalhes sobre cada um dos 13 cursos disponíveis para realização.
